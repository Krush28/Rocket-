How KRISHI-X works

The farmer journey, the system architecture, the agent workflow and the order lifecycle. They are drawn from the running code (see docs/ARCHITECTURE.md).

Farmer journeyArchitectureAgent workflowOrder lifecycle← Pitch deck

1 · Farmer journey (UML sequence)

From one spoken sentence to a delivered, confirmed sale. Every action with consequences waits for the farmer's “yes”.

2 · System architecture

Free and open data in, local AI, deterministic maths, one API for the farmer app and every partner portal.

3 · Agent workflow (one voice turn)

Rules first, the local LLM only for unclear phrasing (and only to pick a tool), with all rupees computed by the 12-agent orchestrator.

4 · Order lifecycle (UML state)

The sale order and its transport booking token; transporters accept, pick up and deliver, and the farmer confirms the sale.
